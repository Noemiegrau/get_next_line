# get_next_line

A C function that reads a file descriptor line by line.

## Table of contents
* [Description](#description)
* [Installation](#installation)
* [Link URL to GitHub Repository](#link-url-to-github-repository)

## Description

get_next_line reads one line at a time from a file descriptor, handling memory management and a configurable buffer size. It can be called repeatedly to read through an entire file, returning each line successively until EOF (end of file).

## Installation

```bash
git clone https://github.com/Noemiegrau/get_next_line.git
cd get_next_line
make
```
